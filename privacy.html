Privacy Policy

Personal Finance on Claude is a private tool used only by its owner, on the owner's own QuickBooks Online company. It has no other users and collects no data from anyone else.

The tool runs on the owner's own computer. It reads and writes the owner's accounting data through the QuickBooks Online API for the owner's personal bookkeeping. The owner uses Claude, an AI assistant from Anthropic, to help with this work, so accounting data is processed by Anthropic as the owner's service provider. That data is not sold or shared with advertisers or data brokers.

Access credentials are stored in the macOS keychain on the owner's computer. This website stores no accounting data, and the owner has added no cookies or analytics to it. It is hosted on GitHub Pages, which may keep standard visitor logs.

The owner can end access at any time by disconnecting the app in QuickBooks Online.
